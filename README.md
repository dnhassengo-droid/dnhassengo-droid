# Hi, I'm Laden Nhassengo 👋

Backend & DevOps engineer at [Dorico Dynamics](https://github.com/Dorico-Dynamics) · Maputo, Mozambique 🇲🇿

[![LinkedIn](https://img.shields.io/badge/LinkedIn-Laden_Nhassengo-0A66C2?style=flat-square)](https://www.linkedin.com/in/laden-nhassengo-49940844b/)

I build the services behind multi-tenant business software (finance and accounting, payroll, HR, assets and document management), mostly in **Go** on **PostgreSQL**, deployed to **Kubernetes**.

### What I work on

- **Go services and APIs**: REST APIs, API gateways, IAM and service-to-service authentication
- **PostgreSQL**: schema design, migrations, row-level security for tenant isolation
- **Event-driven systems**: Kafka producers and consumers, Redis
- **Frontend**: React and Next.js with TypeScript
- **Delivery**: Docker, Kubernetes, Helm, Argo CD, Terraform and GitHub Actions pipelines
